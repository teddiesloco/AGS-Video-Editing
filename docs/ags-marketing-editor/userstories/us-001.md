# Marketing editor acceptance criteria
US-ags-marketing-editor-001: As a business owner, I supply video and a sales/value objective in my coding assistant so it edits for me without requiring editing commands.

AC-001 Given a local talking-head clip and transcript, When the owner approves a proposed plan and the agent renders, Then cuts/reordered speech and subtitles match the approved timeline, with preserved source files.
AC-002 Given actual proof and mood assets, When rendered, Then sampled frames show those assets at specified times and reported exclusive role durations match the output.
AC-003 Given two valid personas, When rendering the same plan, Then font/color changes are visible and Vietnamese caption text remains within the safe box.
AC-004 Given an approved plan, When media, transcript, persona or plan changes, Then rendering final rejects stale approval with E-ags-marketing-editor-002.
AC-005 Given an approved draft, When its bytes change or output already exists, Then final export rejects without overwriting source or destination.
AC-006 Given missing evidence, invalid bounds, nonfinite times, overlapping overlays or a missing font, When validating, Then actionable E-001/003/006 occurs before rendering.
AC-007 Given a plain-language revision, When agent interprets it, Then proposed changed fields are displayed; ambiguous intent is clarified and affected approvals expire.
AC-008 Given a failed job in a batch, When processing completes, Then other valid jobs finish and failure is not labelled successful final.
AC-009 Given each Antigravity/Codex/Claude Code host with its available runtime, When user supplies a video and goal, Then inspect→plan→draft→revise→final executes through installed tools; record evidence per host, explicitly mark unavailable hosts NOT_CHECKED.
AC-010 Given the review prototype at 360/390/430 and 1280px, When switching Loading/Empty/Error/Populated, Then status and relevant actions remain readable without horizontal scrolling.
AC-011 Given a technical PASS, When presenting the draft, Then semantic and aesthetic review remain human responsibilities and viral results are not guaranteed.
